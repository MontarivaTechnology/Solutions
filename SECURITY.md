# Security

If you find a security problem in one of our products, please **don't open a public issue**.

Report it privately instead: on GitHub go to this repository's **Security** tab > **Report a vulnerability**, or use the contact form on [montariva.com](https://montariva.com).

Please include the product and version, what the problem is and how to reproduce it. We'll confirm we received it and keep you updated until it's fixed.

## Supported versions

Only the latest version of each product receives fixes. The current versions are listed in the [README](README.md).
